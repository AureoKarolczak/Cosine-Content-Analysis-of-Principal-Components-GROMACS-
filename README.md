# Cosine-Content-Analysis-of-Principal-Components-GROMACS-
This repository provides a minimal, reproducible workflow to compute the cosine content of the first principal component (PC1) from a GROMACS PCA analysis. The cosine content is a practical diagnostic for sampling convergence: values close to 1 indicate that the dominant mode resembles random diffusion (a cosine function), suggesting that the simulation has not converged to capture biologically relevant collective motions.

📋 Requirements
GROMACS (tested with version 2024.4, but the commands are stable across recent versions)

grep and awk (standard on Linux)

A completed PCA run producing a 2D projection file (e.g., 2dproj.xvg from gmx anaeig -2d)

📁 Input
You need the 2D projection file generated by:

bash
gmx anaeig -s md.tpr -f mdcenter.xtc -n index.ndx -v eigenvec.trr \
           -first 1 -last 2 -2d -proj 2dproj.xvg
This file contains the projection of the trajectory onto PC1 and PC2. The first column is time (or frame), the second column is the PC1 projection, and the third column is the PC2 projection.

🚀 Usage
Best option  — One-liner 
The following command extracts the PC1 projection, computes its cosine content with gmx analyze, and prints the numerical result without GROMACS comment lines:

bash

grep -v "^[#@]" 2dproj.xvg | awk '{print $1}' > /tmp/pc1_tmp.xvg && gmx analyze -f /tmp/pc1_tmp.xvg -cc /tmp/cc_tmp.xvg && grep -v "^[#@]" /tmp/cc_tmp.xvg

What each part does:

Command	Purpose
grep -v "^[#@]"	Removes GROMACS comment lines (starting with # or @)
awk '{print $1, $2}'	Keeps time and PC1 projection columns (required by gmx analyze)
gmx analyze -f ... -cc ...	Computes the cosine content and writes it to /tmp/cc_tmp.xvg
grep -v "^[#@]" (final)	Prints only the numerical result
